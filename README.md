# UTC Time Zone Converter

A lightweight static web application that converts UTC or ISO-8601 timestamps to worldwide IANA time zones.

## Features

- UTC date/time input
- ISO timestamp input, including offsets such as `+0600`
- Searchable region/city time zones
- 12-hour converted time with AM/PM
- Automatic daylight-saving-time handling
- Bangladesh and Nepal quick-select buttons
- No backend or API required
- Suitable for GitHub Pages

## GitHub Pages

This repository is designed to run directly from `index.html` using GitHub Pages.

To publish: open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Expected site URL:

`https://astrax3v2.github.io/utc-timezone-converter/`
